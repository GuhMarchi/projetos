# 🖥️ Tec Gustavo Marchi — Suporte Técnico

Página web desenvolvida para divulgação dos serviços de suporte técnico prestados por **Gustavo da Silva Marchi**, com acesso rápido aos canais de atendimento via Instagram e WhatsApp.

## 🔗 Acesse o projeto

👉 [guhmarchi.github.io/projetos](https://guhmarchi.github.io/projetos/)

## 📋 Sobre o projeto

Este projeto é uma landing page simples e objetiva criada para apresentar os serviços de suporte técnico e facilitar o contato com clientes. A página conta com:

- Apresentação visual dos serviços prestados
- Link direto para o **Instagram** profissional
- Link direto para contato via **WhatsApp**

---
